# From sales to GTM jobs: the one-page checklist

Based on keyword counts from 100 LinkedIn GTM Engineer, RevOps and Growth/Outbound postings (collected Nov 10, 2026). One sample, not a benchmark. Not all roles are remote.

## 1. Know a CRM (HubSpot or Salesforce: named in 62 of 100)
- [ ] I can say how a lead is created, owned and updated in my CRM
- [ ] I can name one field that is often empty and what that breaks
- [ ] I can explain one automatic rule my team's CRM runs

## 2. Understand how leads move (enrich, score or route: 58 of 100)
- [ ] I wrote down how a new lead gets from form to owner: the rule, the owner, and what happens if nothing matches
- [ ] I can say what "enriched" means in one sentence and what is added
- [ ] I can say how a lead's score is calculated, and who decided it

## 3. Learn the automation tools (Clay 33, n8n 28, Zapier 25)
- [ ] I know what Clay, n8n and Zapier are each used for
- [ ] I rebuilt step 2 with 10 made-up leads
- [ ] I can say what happens when the data is missing

## 4. Learn just enough SQL and APIs (APIs 61, SQL 51)
- [ ] I can say what one API request sends and what comes back
- [ ] I can read a simple SQL SELECT with a WHERE and say what rows it returns
- [ ] I know that 41 of the 100 postings mention no Python, JavaScript or SQL at all, so I can start without being an engineer

## 5. Keep proof
- [ ] One page: what the build does, one way it can fail, how I would check it
- [ ] One number from a test, labelled as a test (for example: 8 of 10 made-up leads routed to the right owner)
- [ ] Saved where I can send a link

## Red flags in a posting
- Asks for "GTM Engineer" but lists only web development or only reporting. Read the day-to-day section
- No tools named at all. Ask what the team uses
- Salary missing: most public postings leave it out (the sample had it on 16 of 100)
