# Builder's Desk · Week 10 · Turn the prompt you keep retyping into a skill

One idea this week: if you paste the same prompt into an AI tool every day, that prompt should be a **skill**.

## What a skill is, explained like you're 10

Think of a recipe card. You don't explain to the cook how to make the same dish every single time. You write it once, pin it in the kitchen, and anyone can pick it up and cook it the same way.

A skill is that recipe card for an AI assistant. It's a small folder with one file called `SKILL.md`. At the top there's a name and a one-line description of *when* to use it. Underneath are the steps, the rules and what a good result looks like.

When you ask for something that matches the description, the assistant picks up the card and follows it. Claude uses skills this way, and coding agents like Claude Code, Codex and Cursor can use the same kind of file. Clay has even opened a marketplace of GTM skills built for those tools (https://www.clay.com/blog/introducing-clay-skills-marketplace).

## Why it matters for sales and GTM people

A prompt lives in your head or in a notes app, so every time you use it, it comes out a little different. A skill lives in a file, so it comes out the same for you, your teammate and the new SDR who joined on Monday.

That's the whole business logic: **the value isn't the AI, it's writing your process down once, clearly enough that it can be repeated.** The best reps already do this in their heads. A skill just makes it visible.

## What's in this folder

| File | What it's for |
|---|---|
| `skill-checklist.md` | A 5-question test for whether a task deserves a skill, plus a checklist before you trust it |
| `SKILL-template.md` | A blank fill-in-the-gaps template for your own skill |
| `pre-call-brief/SKILL.md` | A working example: a pre-call research brief for a sales call |

## How to use it in 10 minutes

1. Pick one task you did with AI more than twice last week.
2. Run it through `skill-checklist.md`. If it passes, keep going.
3. Copy `SKILL-template.md` into a new folder named after the task and fill in the gaps.
4. Upload the folder as a skill in Claude's settings (check your plan supports skills), or drop it into your coding agent's skills folder.
5. Use it on a real task, see where the result is wrong, and fix the card, not the output.

Start with the example in `pre-call-brief/` if you want to see a finished one first.
