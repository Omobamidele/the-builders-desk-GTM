# Does this task deserve a skill?

Answer yes or no. Three or more yes answers means write the skill.

1. **Do I do it at least once a week?** If it's a one-off, a normal prompt is fine.
2. **Do I already explain it the same way every time?** If you keep retyping the same instructions, that's the recipe.
3. **Is there a "right way" a new teammate would need to learn?** Your rules, your tone, your format.
4. **Would a wrong answer cost me something?** A bad fact in front of a prospect, a wrong number in a report.
5. **Can I describe what "good" looks like in a few lines?** If you can't, the AI can't hit it either.

## Before you trust it (run through this the first 3 times you use it)

- [ ] The description says *when* to use it, not just what it is
- [ ] Every step is one action, written so a new hire could follow it
- [ ] It says what to do when information is missing (say "not found", never guess)
- [ ] It asks for a source link next to every fact about a person or company
- [ ] It sets a length and a format for the output
- [ ] There's one example of a good output inside the file
- [ ] I tested it on 3 real cases and fixed the card each time it went wrong
- [ ] Anything private (client names, passwords, API keys) is out of the file

## Signs your skill needs fixing

- The output changes a lot between runs, so the steps are too vague
- It invents details, so the "if missing" rule is weak or absent
- You keep editing the same part of every output, so that part belongs in the rules
