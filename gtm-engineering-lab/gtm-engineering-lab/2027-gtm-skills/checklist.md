# 2027 skill checklist

Tick what you already do at work. The order follows how often each capability showed up in the 113 listings posted 14 Oct–24 Nov 2026. A tick means you have done it, not that you have only read about it.

## Table stakes (start here if a box is empty)

These are the asks that show up most often. They are not new, and they are not optional.

- [ ] Work in a CRM, usually Salesforce or HubSpot (95 of 113 listings)
- [ ] Build or maintain reports, dashboards, or a forecast (89 of 113)
- [ ] Query data with SQL, or work with a warehouse such as BigQuery or Snowflake (69 of 113 mention SQL or a warehouse; 59 mention SQL itself)
- [ ] Enrich, score, or route leads and accounts (62 of 113)
- [ ] Keep CRM data clean: hygiene, deduping, data quality (50 of 113)
- [ ] Sit with sales or marketing leaders and translate what they need into a system (51 of 113)
- [ ] Connect tools with APIs or webhooks (38 of 113)

## The 2027-forward layer

This is what is newly common in the same listings. You do not need all of it on day one. You should be able to point to one real example of the first item.

- [ ] Build, ship, or run an AI agent or agentic workflow that does a real GTM or RevOps task (36 of 113)
- [ ] Use an LLM (Claude, ChatGPT, or similar) inside that work, not only as a chat window (54 of 113 name one)
- [ ] Put a check on the output: evals, guardrails, or a human review step (11 of 113)
- [ ] Know what MCP is, and have used it or a similar way to hook a model up to your tools (10 of 113 name MCP)
- [ ] Be comfortable building faster with Claude Code, Cursor, or a similar AI coding tool (10 of 113)

## Also useful, asked less often in this sample

- [ ] Run outbound or sequences, ideally off a real signal rather than a raw list (30 mention outbound; 8 mention signal- or intent-based outreach)
- [ ] Work in Clay, n8n, Zapier, Make, or Workato (41 of 113 name at least one; 36 name Clay)
- [ ] Watch email deliverability (SPF, DKIM, DMARC, inbox placement) (7 of 113)
- [ ] Ship something with Git or a simple CI/CD check (12 of 113)

## Start here this month

1. If you cannot yet do the first four table-stakes boxes, do those first. A 2027 skill does not help if the CRM and the routing are a mess.
2. Then pick one repetitive GTM or RevOps task (a research brief, a lead enrich-and-route, a weekly forecast cleanup) and build a small agent or LLM workflow that does it.
3. Write down how you check the output before anyone uses it. That is the eval/guardrail piece, even if the listing uses fancier words.
4. Save the build and one honest number (time saved, error rate, or volume handled). That is what a hiring manager or a founder will ask for.
