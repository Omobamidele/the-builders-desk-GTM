Skill Ladder Self-Check

Where Do You Actually Stand?

Check what you currently do — not what you've read about or plan to learn. Be honest; the tool is only useful if you are.

Tier 1 — Low-Code Operator
I can build a working Clay table from scratch.
I can set up a Zapier or Make automation without help.
I can configure CRM workflows in HubSpot or Salesforce.
Tier 2 — Mid-Level Technical Builder
I can write a basic Python or JavaScript script on my own.
I can call an API directly and handle the response myself.
I can write SQL queries with joins to pull the data I actually need.
I've extended a no-code workflow with custom code when the tool hit a wall.
Tier 3 — High-Code Engineer
I've built a pipeline that moves data on a schedule, without me triggering it.
I use a data warehouse (Snowflake, BigQuery, etc.) as part of my workflow.
I use AI coding tools (Cursor, Claude Code) to build tools instead of waiting on vendors.
I've replaced a paid vendor tool with something I built myself.
