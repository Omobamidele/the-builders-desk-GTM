# Cold email that opens a discussion (one page)

**Goal:** sound like an internal note, not a pitch. No "hope you're well." No fake Re:. No "got 20 minutes?"

**Persona / ICP:** _______________   **Problem (their words):** _______________
**Signal (link or none):** _______________   **Soft offer (one line):** _______________

## Two jobs of email 1
1. Get it opened (right person + honest subject)
2. Start a discussion (one thread they can reply to in one line)

If either job fails, rewrite — don't add more pitch.

## Before you send — yes/no

| # | Check | Yes? |
|---|---|---|
| 1 | Right ICP / persona (wrong person = dead email no matter how good the copy) | |
| 2 | Sounds like an internal note opening a discussion, not a brochure | |
| 3 | Under ~100 words | |
| 4 | No Re: / "quick question" / "hope you're well" / "got 15–20 minutes?" | |
| 5 | Soft offer (help / idea / observation) — not "we help companies like yours…" | |
| 6 | One easy reply path (yes/no or one-line answer) | |
| 7 | Real signal with a link, or honest none | |
| 8 | No invented results or customer names | |

## Skeleton (internal-note style)

Subject (plain): _______________

Hi {{first_name}},

[One line: why them / what you noticed — no throat-clearing]

[One line: the problem in their world]

[Soft offer — something useful, not a calendar ask]

[Discussion opener — a question they can answer in one line]

—

## Kill list
- Hope this finds you well
- Fake Re: / fake forwarding
- Asking for 15–20 minutes of their time
- Hard CTA ("book a call", "schedule here")
- Pitching the whole product in paragraph one
